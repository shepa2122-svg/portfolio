САЙТ-ВИЗИТКА VLADIMIR.ENGINEERING

Как открыть:
1. Распакуйте архив в любую папку на компьютере.
2. Откройте index.html двойным щелчком мыши.
3. Сайт откроется в браузере. Для просмотра интернет не нужен, кроме загрузки внешних шрифтов (если интернет доступен).

Что обязательно заменить перед публикацией:
- your-email@example.com — ваша рабочая почта (в двух местах).
- @your_telegram — ваш Telegram.
- Графические иллюстрации в карточках портфолио — на реальные изображения ваших проектов.
- При желании дополнить имя фамилией и уточнить стаж/образование.

Редактирование:
Откройте index.html в Visual Studio Code. Тексты находятся прямо в HTML, стили — внутри блока <style>, фильтрация портфолио — внизу файла.

Сейчас это локальная статическая версия: никакой сервер, база данных или платный хостинг не требуются.
