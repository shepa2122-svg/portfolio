КАК ДОБАВИТЬ НОВЫЙ ПРОЕКТ НА САЙТ
=================================

Что понадобится: файл index.html, рядом с ним папка assets, текстовый редактор
(Блокнот, VS Code или Notepad++).


ШАГ 1. ПОДГОТОВЬ ФАЙЛЫ
----------------------
Дай файлам короткие имена латиницей, без пробелов, скобок и русских букв:

  render.jpg          главный рендер (он станет обложкой карточки)
  render-2.jpg        дополнительные рендеры, если есть (render-3.jpg и т.д.)
  instruction.pdf     инструкция (если есть)
  drawings.pdf        конструкторская документация (если есть)

Расширение должно быть настоящим. В Проводнике включи: Вид -> Расширения имён файлов.
Рендеры лучше сжать до 1600-2000 px по длинной стороне (до 1-2 МБ), так сайт
быстрее открывается, особенно на телефоне.


ШАГ 2. СОЗДАЙ ПАПКУ ПРОЕКТА
---------------------------
Внутри папки assets создай папку с коротким именем латиницей, например:

  assets\shezlong-2165
  assets\gorka-01
  assets\playground-park

Положи в неё файлы из шага 1. Итог должен выглядеть так:

  vladimir_engineering_portfolio\
    index.html
    assets\
      shezlong-2165\
        render.jpg
        drawings.pdf
      gorka-01\
        render.jpg
        render-2.jpg
        instruction.pdf
        drawings.pdf


ШАГ 3. ДОБАВЬ ПРОЕКТ В index.html
---------------------------------
Открой index.html в текстовом редакторе (правая кнопка -> Открыть с помощью).
Найди строку:  const PROJECTS=[
Это список всех проектов. Скопируй блок любого существующего проекта, вставь его
ПОСЛЕ предыдущего и поставь между ними запятую.

Шаблон блока:

  {id:'gorka-01',group:'outdoor',title:'Название проекта',
    desc:'Короткое описание: размеры, материал, возраст, особенности.',
    renders:['assets/gorka-01/render.jpg','assets/gorka-01/render-2.jpg'],
    manual:'assets/gorka-01/instruction.pdf',
    docs:[{title:'Конструкторская документация',file:'assets/gorka-01/drawings.pdf'}]}

Что значит каждое поле:

  id        уникальное имя проекта латиницей, не повторяется у разных проектов
  group     раздел каталога:
              outdoor  - Уличные
              indoor   - Закрытые
              maf      - МАФ
  title     название на карточке
  desc      описание
  renders   список рендеров в квадратных скобках через запятую.
            Первый - обложка, остальные - миниатюры в галерее.
  manual    путь к PDF инструкции. Если инструкции нет: manual:''
  docs      список документов. Если документов нет: docs:[]
            Если их несколько, перечисли через запятую:
              docs:[
                {title:'Чертежи',file:'assets/gorka-01/drawings.pdf'},
                {title:'Спецификация',file:'assets/gorka-01/spec.pdf'}
              ]


ШАГ 4. СОХРАНИ И ПРОВЕРЬ
------------------------
Сохрани index.html, открой двойным кликом, нажми F5 (или Ctrl+F5).
Путь на сайте: Портфолио -> Игровое оборудование и МАФ -> нужная вкладка -> карточка.


ВАЖНЫЕ ПРАВИЛА ЗАПИСИ
---------------------
 1. Между проектами ставится запятая. После ПОСЛЕДНЕГО проекта запятой нет.
 2. Весь список заканчивается на  ];  - не удаляй эту строку.
 3. Текст пишется в одинарных кавычках '...'. Внутри текста не используй
    одинарную кавычку: для названий бери «ёлочки». Пример: title:'Горка «Лиса»'
 4. Описание должно быть в одну строку, без переноса внутри кавычек.
 5. Пути пиши через обычный слэш /, а не через обратный.
 6. Все буквы в именах файлов и в index.html должны совпадать точно, включая
    расширение (.jpg - это не .jpeg и не .png).


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
 * Каталог не открывается или пустой экран: в списке проектов нет запятой или
   потерялась кавычка/скобка. Нажми F12 -> вкладка Console: там будет написано,
   в какой строке ошибка.
 * Вместо рендера серая плашка "РЕНДЕР": браузер не нашёл картинку. Проверь папку,
   имя файла и расширение (чаще всего .png вместо .jpg или двойное .jpg.jpg).
 * PDF не открывается: то же самое, проверь имя файла и путь в docs/manual.
 * После правок ничего не изменилось: обнови страницу через Ctrl+F5.


КАК УДАЛИТЬ ИЛИ СКРЫТЬ ПРОЕКТ
-----------------------------
Удали его блок целиком (от { до }) вместе с запятой. Файлы в assets можно оставить
или удалить - на сайт это не влияет.


ПЕРЕД ПУБЛИКАЦИЕЙ В ИНТЕРНЕТЕ
-----------------------------
Когда сайт будет выложен, после каждого добавления проекта нужно заново загрузить
index.html и новую папку assets/<проект> на хостинг. Подробно разберём, когда
будем публиковать.
